# Open Source Software Maintenance (OSS)

Website and content for the OSS maintenance platform behind PostgreSQL tools:

  - pgloader — heterogeneous database migrations
  - pgcopydb — PostgreSQL-to-PostgreSQL migrations & upgrades
  - pg_auto_failover — high availability automation

This site presents the maintenance model, projects, roadmap, and support
options.

## Purpose

Open source powers production systems, but maintenance is often unfunded.

This project provides a simple, productized model:

  - Users fund the tools they depend on
  - Work is prioritized through a queue + SLA
  - Fixes and improvements ship in quarterly releases

The result is predictable, accountable upstream maintenance.

## Key Concepts

  - Priority queue — paid tiers move work forward
  - Async-first — no meetings, no consulting overhead
  - Quarterly releases — predictable delivery cadence
  - Upstream-first — fixes happen at the source
