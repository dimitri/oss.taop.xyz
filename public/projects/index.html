Our Projects

Critical PostgreSQL tooling, professionally maintained

We maintain a focused selection of open source tools that address core PostgreSQL operational needs: migrations, data movement, and high availability. Each project is production-proven, widely adopted, and backed by dedicated maintenance.

pgloader

Database Migration Tool

pgloader loads data from various sources into PostgreSQL. It supports MySQL, SQLite, MSSQL, Oracle, and more—with automatic schema conversion and high-performance parallel loading.

  • Multi-source database migration
  • Automatic schema conversion
  • High-performance parallel loading
  • Data type transformation
Details GitHub

pgcopydb

Database Copy Tool

pgcopydb copies a PostgreSQL database to a target server with minimal downtime. It uses logical replication for live copies and supports large databases.

  • Live database cloning
  • Logical replication support
  • Minimal downtime migration
  • PostgreSQL version upgrade
Details GitHub

pg_auto_failover

High Availability Manager

pg_auto_failover monitors PostgreSQL and automatically manages failover to maintain high availability. Built on PostgreSQL native features.

  • Automatic failover
  • Zero data loss
  • PostgreSQL native design
  • Simple orchestration
Details GitHub
