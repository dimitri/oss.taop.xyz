pgloader

Migrate to PostgreSQL from any source

pgloader enables fast, reliable migrations from heterogeneous databases to PostgreSQL. It handles schema conversion, data loading, and real-world edge cases so migrations complete—not stall.

What pgloader does

Automated, high-performance migrations

pgloader migrates data from MySQL, SQLite, MSSQL, and other sources to PostgreSQL. It automatically converts schema definitions, maps data types, and loads data in parallel for high throughput.

Why it matters

Migrations are high-risk operations

  • Database migrations are time-sensitive and failure-prone
  • Edge cases in schemas, data types, and constraints can block progress
  • pgloader is designed to handle those cases
  • Reduces migration risk in production environments

Typical use cases

Where pgloader fits

  • MySQL to PostgreSQL migrations
  • Legacy database consolidation
  • CI/test dataset loading
  • One-off or repeatable migration workflows

Key capabilities

Built for real datasets

  • Automatic schema conversion
  • Data type mapping and transformations
  • Parallel data loading
  • Support for multiple source systems

Current focus

Active maintenance areas

Current work focuses on migration edge cases, driver compatibility, SQL parsing improvements, PostgreSQL version support, and performance on large datasets.

How maintenance works

Queue, SLA, quarterly releases

Work is prioritized through a queue. Supported users receive priority handling, with defined response times. Fixes and improvements are grouped and shipped in quarterly releases.
